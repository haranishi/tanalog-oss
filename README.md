# タナログ — OSS版

本・マンガ・ゲームを棚に並べ、作品ページとランキングを表示する Next.js / TypeScript のプロトタイプです。

## 起動

```sh
npm ci
npm run dev
```

`npm run build`、`npm run start` で本番形式の起動ができます。
トップ、`/w/[id]`、`/ranking` が主な画面です。

## デモデータ

収録した10作品の紹介文・感想・評価はデモ用です。実際の利用者の投稿や集計値ではありません。
表紙はCSSで作ったプレースホルダーで、作品の書影やゲーム画像を同梱していません。
作品名・著者名は作品を識別するための記載です。各作品の本文・画像・商標をMITで提供するものではありません。
購入ボタンは楽天の検索ページ等へ移動します。書誌APIからのデータ取得は実装していません。

## 実データ・運用への移行

書影、書誌データ、利用者投稿、アフィリエイトを追加する場合は、それぞれの提供元の現行規約・表示条件・保存条件を確認してください。
このソース公開はAPIデータの再配布許可や、サービス運営の法的確認を意味しません。
